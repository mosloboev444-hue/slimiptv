# Изменения

## 1.2

- встроенный плейлист заменён на двухпроходно проверенный: 1252 канала, которые ответили дважды подряд
  (источники: Free-TV/IPTV, ngrch/iptv, iptv-org);
- в списке каналов появились логотипы (асинхронная загрузка с кэшем);
- добавлен скрипт `tools/two_pass_verify.py` — двухпроходная проверка с сохранением логотипов и номеров.

## 1.1

- исправлен вылет (ANR) при включении недоступного канала: подготовка потока перенесена в фоновый поток;
- колбэки плеера защищены токеном поколения, `reset/release` в фоне;
- плеер переведён на `TextureView`;
- добавлен `tools/verify_playlist.py`.

## 1.0

- первый релиз: список каналов, воспроизведение HLS/HTTP, управление пультом, обновление плейлиста по MENU.
